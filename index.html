Trekking infographic editor

Chỉnh sửa nội dung, xem trước và tải poster PNG.

Đang tải config/settings.json...

Để lưu cài đặt vào repo, chạy python server.py rồi mở http://127.0.0.1:8765. Dùng Xuất/Nhập JSON để chuyển cài đặt giữa các trình duyệt.

Xem trước

Ảnh nền mặc định là file JPG đặt cạnh trang HTML. Nếu trình duyệt không cho tải ảnh, hãy dùng “Chọn ảnh nền” và chọn lại file JPG.
